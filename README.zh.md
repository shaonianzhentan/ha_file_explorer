## 安装

安装完成重启HA，刷新一下页面，在集成里搜索`文件管理`即可

[![Add Integration](https://my.home-assistant.io/badges/config_flow_start.svg)](https://my.home-assistant.io/redirect/config_flow_start?domain=ha_file_explorer)

## 功能

**文件管理**

- [x] 新建文件或文件夹
- [x] 重命名文件或文件夹
- [x] 删除文件或文件夹
- [x] 上传文件或整个文件夹（也能直接拖拽，并带可确认的上传队列）
- [x] 下载文件或文件夹（文件夹自动打包为 zip）

**查看与编辑**

- [x] 内置编辑器修改文本文件内容
- [x] 常见格式语法高亮、代码格式化与格式检查提示
- [x] 预览图片与视频

**浏览与导航**

- [x] 面包屑路径导航
- [x] 按文件名筛选与搜索
- [x] 列表 / 平铺两种视图切换，可显示文件大小与修改时间

**集成特性**

- [x] 原生 HA 自定义面板（ES module 加载，不使用 iframe）
- [x] 跟随 HA 主题（亮色 / 暗色）
- [x] 跟随 HA 语言（简体中文 / English / Русский）
- [x] 可切换 HA 侧边栏，并展示项目详情（大小、时间、权限、路径）
